核对来源：

- `server/plantillas/skill_sin_exclusion.xml.zlib` 与 `client_tables.json` 的36个分支。
- `D:\天使之恋Online\update29.pak` 的 `setting/gb/skill.xml`。
- `D:\Angels-Online-Preservation\client-local\update32.pak` 的 `setting/big5/skill.xml`。

三份技能表的36个 ID、属性数值、职业积分和训练标记一致。与仓库“无互斥”表比较时，中文客户端多出14个互斥字段；这是该模板特意去除技能互斥造成的区别，不是 ID 错位。本次没有给实际中文客户端套用英文客户端二进制补丁。

职业 ID 与技能 ID 是不同编号体系：职业14是刺客，技能14是盾防。影刃的 `pt14=10` 也明确指向刺客，不能按旧代码把职业14当炼金生产职业。

## 二、修复范围

1. 新增 `server/ramas.py` 作为统一分支名称、生产技能和生产职业集合；GM解析、显示名和玩法引用保持一致。
2. 影刃初始法术5401/5406/5411归属30；轻装32不再误领刺客法术。卷轴学习、按分支学习技能、重新登录和换技能走同一映射。
3. 新手影刃19856、所有影刃武器类别和竞技场影刃奖励66303归属30。轻装奖励32保持原样；影刃为右手单持，不能按剑斧双持规则发两把。
4. 刺客不再被判为生产职业、误发生产机甲，也不再作为高等级新增技能槽的生产占位分支。
5. 影刃按武器/法术分支获得战斗技能经验，不再从生产、采集获得影刃经验。幻化和奇袭补齐原表允许的远程攻击训练路径。
6. 战斗、技能经验券、农场、每日活动、天使小学和赛事奖励统一上限：影刃/轻装最多人物等级；真正的生产技能仍允许人物等级+11，并遵守全局等级上限。
7. 补齐30/35/36漏算的基础属性和影刃装备条件成长；轻装原有防御、灵敏和负重不变。
8. 旧版本误发并已保存的影刃法术不直接删除；没有装备分支30时，战斗入口拒绝使用，避免轻装成为刺客技能授权。已有合法学习记录保留。

## 四、验证方式与边界

新增 `tools/test_shadowblade_branches.py` 和 `tools/test_shadowblade_runtime.py`，测试全部36个分支名称、435条影刃法术和1522条武器记录、职业选择报文、新手装备与技能、技能银行双向切换、SQLite保存/重载、经验上限、属性、历史误发法术拦截和竞技场奖励。

所有测试使用隔离 `AO_DATOS` 及临时SQLite，未向真实账号发送测试报文。另检查既有GM、换技能、额外技能槽、竞技场、中文名称、画面亮度及台服技能实现的回归用例。

扩展测试中，部分生产、每日活动、问答地图和战斗用例因原始XML/地图缺失或旧测试设置不完整失败；加载Git原版相关模块，在同一环境复现了这些失败。本次没有修改这些无关系统，也不宣称全仓库测试通过。

本机结果：重点回归 **228项通过**；扩展回归 **121项通过、33项失败**，剩余33项都在Git原版基线的失败集合中。原来用轻装32施放影刃连击且未装备武器的两个战斗测试，改用正确的30及影刃武器后通过。修改模块通过 `py_compile`，`git diff --check` 无异常。测试结果保存在忽略目录 `scratch/skill-focused-results.xml`、`scratch/skill-broad-results.xml` 和 `scratch/skill-baseline-results.xml`。

**仍需客户端实机验收：**创建刺客后看技能图标、普通攻击与影刃招式、卸装前后属性、技能天使切换、退出重进。服务端报文和存档测试不能代替客户端动画/UI验证；其他高级技能、活动及完整台服客户端兼容性仍按游玩限制文档处理。

## 五、建议你如何验收

1. 原有弓手可直接登录，不需要删号；轻装保留，初始技能不再额外授予影刃招式。
2. 用测试角色选择影刃30、强身12、格斗13、幻化35、奇袭36、轻装32：应为刺客，获得一把影刃，不额外送生产机甲。
3. 装备影刃打怪，观察30获得技能经验；改持其他武器时，30不应靠普通攻击训练。
4. 通过技能天使换出30、换回30，然后重新登录，确认30与32的等级/经验没有互相覆盖。
5. 不要执行任何“交换存档30/32”的修复脚本；此项目原先的问题是解释错 ID，而不是存档需要改 ID。
