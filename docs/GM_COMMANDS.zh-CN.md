# GM 指令中文手册

核对日期：2026-11-20。依据当前 `server/app.py`、`server/gm.py` 和各活动模块，不是旧的 `GM_ITEM_COMMAND_FOR_AI.md` 待开发规格。

**这是中文解释版，命令本身仍要输入英文。** 本次没有向在线角色执行任何 GM 命令，没有发道具、改等级或改存档。

## 1. 怎样输入

推荐角色进入世界后，在游戏聊天栏输入以 `/` 开头的完整命令，例如：

```text
/help
/item 19814 1
```

第二行会尝试给当前角色一个 19814 号物品。执行前请先查道具目录；不知道效果的物品不要批量发。

- `<参数>` 表示必填，`[参数]` 表示可选；实际输入时不带尖括号/方括号。
- 参数之间用空格，数字用普通半角数字。
- 游戏内命令作用于发出命令的角色；改等级、物品、任务、成就等会影响存档。
- 源码**没有在 GM 分派处做管理员账号权限检查**。本地单人方便，但不能直接用于公开多人服。
- 控制台和 `data/gm.txt` 也有入口，通常选最后连接的世界角色。当前隐藏启动没有交互控制台；**文件队列不建议作为首选**：当前程序同时启动两套读取同一个文件的消费者，支持命令不完全相同，谁先读到可能影响执行。多人时还可能改错角色。
- 不要把整本手册复制进 `data/gm.txt`，该文件内容会被当命令消费并清空。

## 2. 先了解当前解析问题

下列情况已用解析函数验证，未在真实角色上执行：

| 情况 | 影响与替代方法 |
| --- | --- |
| 客户端可能去掉命令开头 `/`；服务端无斜杠识别要求首词至少 3 字母 | `/aa`、`/hb`、`/tw`、`/i`、`/lv`、`/e` 等短名可能无效；使用下面的完整名称 |
| `/quest` 出现在帮助和辅助模块，但主解析器没有分支 | 不承诺游戏聊天可用；不要用它修复主号任务进度 |
| `/ball reset` 在辅助模块存在，主解析器未接通 | 用 `/casa resetball` |
| `/skilllevel` 有执行分支但没有解析入口 | 不能当可用指令；`/levelall` 会同时改人物和技能，不是等价的“仅改技能” |
| 主 GM 输入只识别 ASCII | 中文技能名、中文公告不保证被识别；技能优先用数字 ID 或表中英文别名 |

**下表使用优先可通过主解析器的长名称。** `/help` 内容本身也有过时项目，不代表列出的每个别名都已连通。

## 3. 道具、等级、技能

| 命令 | 中文说明 | 注意 |
| --- | --- | --- |
| `/help` | 显示服务器帮助 | 帮助不完全等于可用命令清单 |
| `/item <ID> [数量]` | 给自己物品，默认 1 件 | 数量限制为 1～9999，拒绝不存在 ID；背包不足可能失败 |
| `/give <ID> [数量]` | `/item` 的长别名 | 推荐仍统一用 `/item` |
| `/level <等级>` | 设置人物等级 | 当前范围 1～481，并重置人物当前经验为 0；升级会影响 HP/MP、技能槽 |
| `/levelall <等级>` | 设置人物等级和已装备技能分支等级 | 经验清零，会快速破坏正常练级进度 |
| `/skills [技能等级上限]` | 学习当前装备分支及对应通用系列的技能，保留每系列符合上限的最高阶 | 这是“学会法术/招式”，不是把分支升到该等级；省略上限会放宽学习限制 |
| `/skillsall [技能等级上限]` | 学习符合上限的所有阶技能 | 不是学习所有职业；仍基于当前装备分支 |
| `/skills5 [技能等级上限]` | 只学习 V 阶技能 | 可学习内容取决于分支和技能表 |
| `/clearskills` | 清空已学习技能记录和快捷栏中的法术格 | 保留分支，初始技能可能重登恢复；旧图标通常需重登才消失 |
| `/rama <原分支> <新分支>` | 替换一个装备中的技能分支 | 支持 ID/英文名；原分支等级存入技能库，新分支恢复其库存等级 |
| `/rama add <新分支>` | 在允许槽位内添加分支 | 不突破等级槽数；额外槽门槛 301/351/401 |
| `/rango` | 爵位增加 1 级 | 上限 20；不是人物等级 |
| `/rango <1..20>` | 设置爵位并补足对应最低功勋 | 不把已有更多功勋扣掉 |
| `/recipes [类别] [技能等级上限]` | 学习制作配方 | 默认 `all`；仍要求对应制造台、技能和材料；上限参数 1～1000 |

配方类别：`all` 全部、`weapon` 武器、`armor` 防具、`sewing` 裁缝、`craft` 工艺、`cooking` 烹饪。

例子（按需要单独选择，不要全部执行）：

```text
/item 19814 1
/skills 100
/recipes weapon 100
/rama 9 1
```

最后一条把装备中的剑术分支 9 换成生命分支 1；只有确实想换职业方向时才使用。

## 4. 宠物

操作对象依次为：已召唤宠物；否则第 9 槽宠物；否则背包找到的第一只。先把目标宠物召唤出来，减少改错对象的风险。

| 命令 | 效果 |
| --- | --- |
| `/pet level <等级> [经验]` | 设置宠物等级及当前经验，等级按宠物自身上限裁剪 |
| `/pet exp <经验>` | **设置**本级经验，不是累加；限制在本级升级门槛以下 |
| `/pet path 1` 或 `/pet path 2` | 设置成长分支，1=`mean`，2=`nice` |
| `/pet evolve 1` 或 `/pet evolve 2` | 直接调用指定分支进化，属于测试操作 |

## 5. 公会、农场、图腾

| 命令 | 效果 |
| --- | --- |
| `/guildlevel <1..10>` | 设置自己所在公会等级，并至少补足该等级声望；不是创建公会 |
| `/guildrep <数值>` | 设置公会声望，必要时提升等级；降低声望不一定降低已取得等级 |
| `/farm enter` | 进入公会农场，仍受公会等级/资格限制 |
| `/farm seeds`、`/farm tools`、`/farm pests` | 农场测试辅助；会涉及发放测试物品或状态，主号慎用 |
| `/plant <作物ID> [地块ID]` | 在农场播种，参数是作物 ID，不是背包种子道具 ID |
| `/totemwar` | 查看图腾战和领地状态，替代 `/tw` |
| `/twstart [分钟]` | 开启或重设计时的图腾战 |
| `/twstop` | 停止图腾战 |
| `/settw <战场ID或200..207> <公会ID>` | 直接更改领地归属，慎用 |
| `/twtotem <1..8>` | 设置当前图腾战场图腾等级 |
| `/notice <英文文字>` | 向在线玩家发顶部公告；中文输入路径未保证 |

## 6. 竞技场与圣战（测试轮次）

**开启不等于传送入场。** 仍须入场并满足金币、石头/通行证等要求。当前 `modo_pruebas=true`、测试收费开启；官方奖励不完整，见游玩限制文档。

| 命令 | 效果 |
| --- | --- |
| `/aastart [战斗分钟] [等级组参考等级] [报名分钟]` | 开 Arena；默认战斗 30 分钟、参考自己等级、报名 15 分钟 |
| `/aastop [参考等级]` | 取消相应组别 Arena，不作为正常胜利结算 |
| `/angelarena status` | 查看 Arena 状态，替代 `/aa status` |
| `/angelarena lobby` | 去报名大厅 |
| `/angelarena enter` | 报名/进入；不在大厅时先去大厅，加载完成后需再执行一次 |
| `/angelarena watch` | 观察者入场 |
| `/angelarena begin` | 提前结束报名、开战 |
| `/angelarena finish` | 按当前状态结算；多人仍存活时不凭空指定冠军 |
| `/hbstart [战斗分钟] [报名分钟]` | 开 Holy，默认 60 分钟、报名 15 分钟 |
| `/hbstop` | 取消 Holy |
| `/holybattlefield status` | 查看 Holy，替代 `/hb status` |
| `/holybattlefield lobby`、`enter`、`watch`、`begin`、`finish` | 与 Arena 对应行为相同，Holy 不再附等级参数 |

Arena 的 lobby/enter/watch/begin/finish 可附参考等级。三种战争不是同一个系统：Arena/Holy 不等于图腾战，也不等于公会联赛。

## 7. 每日活动、问答、公会联赛

| 命令 | 效果 |
| --- | --- |
| `/daily start <活动> [战斗分钟] [报名分钟]` | 同时开启活动各等级组；默认 30 分钟、报名 0；参考当前实现推荐这个简单格式 |
| `/daily enter <活动>` | 按自己等级进入活动 |
| `/daily status <活动>` | 查询活动状态 |
| `/daily finish <活动>` | 结算该活动各组别 |
| `/daily stop <活动>` | 取消各组别，不按获胜结算 |
| `/quiz start [报名秒数]` | 天使小学问答，默认报名 10 秒 |
| `/quiz enter`、`status`、`finish`、`stop` | 加入、查询、结算、停止问答 |
| `/gvg start [报名秒数] [战斗秒数]` | 开公会联赛测试；默认报名 60 秒，战斗时长取配置 |
| `/gvg register [1..8]` | 报名相应联赛场地 |
| `/gvg enter`、`status`、`finish`、`stop` | 加入、查询、结算、取消联赛 |

每日活动参数：`bleach`（Bleach of Red）、`faction`（Faction Showdown）、`guard`（Angelic Guard）、`swindle`（Swindle World）、`quick`（Quick Reflexes）、`joy`（Joy Angel Village）、`happiness`（Happiness Guard）。以游戏中文活动窗口为准，不把这些英文别名翻译后输入。

## 9. 查道具与安全使用建议

- 推荐：[中文离线道具目录](../data/localization/items.zh-CN.html)，支持 ID/中文/英文/分类搜索，等级区间、品质和中文映射筛选，点击表头或下拉框按等级/名称/分类排序，可分页 20–200 条并复制 `/item ID 1`。
- 原项目：[图标版英文道具目录](../items.html)，较旧，80,327 条。
- 当前数据库：`corpus/content.db`，`item` 到 `item9` 合计 83,923 个去重数字 ID。查表不等于这些道具在当前客户端都有效。
- 中文映射缺失的 855 个 ID 不等于全部不能用，但优先视为需核验；有映射也不保证图形、法术或功能完整。
- 建议先小号、一次一件、确认效果后再决定是否批量发。不要直接给自己成千上万件未知道具。
- 正常退出游戏后备份 `data/cuentas.db` 或采用 SQLite 在线备份；不要在运行时用空 JSON 覆盖存档。

目录生成工具只读数据库，不修改道具或客户端。以后资料更新后可重新生成：

```powershell
Set-Location -LiteralPath 'D:\Angels-Online-Preservation'
.\.venv\Scripts\python.exe tools/build_item_catalog_zh_cn.py
```

生成页保存在已忽略的本机 `data/localization/`，不把客户端派生名称目录自动提交到Git。浏览器自动预览因不允许 `file:` 地址未完成；已验证生成数据、脚本语法以及模拟DOM下的搜索/筛选/分页。可以自己在资源管理器双击HTML打开。

本次只检查解析、源代码和资料，不声称已经用当前客户端把每个 GM 功能实机跑通。
