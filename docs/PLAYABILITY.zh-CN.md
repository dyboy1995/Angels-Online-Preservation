# 当前游戏能玩到什么程度？哪些问题会影响游玩？

核对日期：2026-11-20。环境：当前仓库、本机 Python 服务端、`D:\天使之恋Online` 简体 8.6.5.7 客户端。

## 结论

**可以当有相当多内容的本地怀旧服玩，但不能当“完全还原、全功能、长期平衡已经验证”的正式服。** 常规教学、打怪、升级、装备、商店、仓库、生产、宠物、房屋等已有实现。你已经实际确认进入世界和画面亮度恢复；这不等于其他所有系统都已对这版中文客户端验证。

最初版本为 README + 源码/配置/数据审计，不是完整的游戏客户端验收。后续已针对影刃/轻装问题修正服务端并增加隔离数据库回归测试；没有删除真实角色或交换存档中的技能 ID，倍率保持不变。其他系统仍不代表已经完成中文客户端实机验收。

## 二、关于你设定的 1 / 100 / 10 倍

当前配置仍是人物基础经验 **1**、技能基础经验 **100**、掉落基础倍率 **10**；自动周末加倍关闭，暴击伤害仍 **1.5 倍**、金币基础倍率仍 **7.5 倍**。

**人物经验1倍并不等于整个游戏恢复“官服1倍节奏”。**

- 道具/技能增益仍可额外加经验。
- 任务、固定奖励、兑换券与活动经验走各自规则，不一定套同一个基础倍率。
- 当前 `daily_schedule.json` 开启每 **10秒** 一次出席奖励：人物经验 `4800×等级`，最低50,000、最高2,000,000，技能经验100；具体发放还受活动参与资格检查。这是项目自己的活动设置。
- Holy 有独立比例经验奖励；公会农场按等级需求百分比给经验。
- 普通怪物掉落路径 `min(0.95, 0.90×倍率)` 有95%上限；10倍不会让每个怪物掉10件，也不代表各稀有物品权重都乘10。

**实际建议：**如果你想慢慢按1倍练人物，目前先避开高额活动/经验道具；将来应单独统一任务和活动经验政策，而不是只改一个倍率。此次不擅自改你的活动设置。

## 三、有功能，但不是官方完整复原

- **每日活动**：本地每周轮换，通常18:00/21:00、15分钟报名、30分钟战斗，按本机时间。波次节奏、部分奖励数量/概率是兼容参数。服务端重启会取消未完轮次，不给虚构防守胜利；已结算待领奖记录会保留。
- **公会战**：积分、奖励和部分平衡配置明确标为本地规则，不是完整恢复官方全部数值。
- **礼包/掉落**：一部分盒子依据描述文字推导内容，没有官方掉落表时不能保证官方概率。有 ID 也不代表能开/能生效。
- **成就**：覆盖很多但并非全部。README 的3248/4351是历史统计，没有在本次重新计算；可能存在做了某件事但对应未接入成就不动的情况，不应承诺全成就可完成。
- **中文**：NPC/怪物名称和部分参数提示已处理；服务器自写英文对话/提示未全译，角色名、公会名、聊天输入等路径也未全面完成中文编码适配。
- **部分高级物品法术缺定义**：项目曾记录 Great Enma 82771..82777 引用缺失法术，定制 IGG 做了空指针保护，但没有补出法术效果。不能把那个特定可执行文件补丁直接用于简体客户端，也不能断言简体一定出现同一崩溃。
- **社交小游戏**：五子棋、Bingo、黑白棋、大老二已实现，不使用角色金币赌注；文档仍列回合超时未实现，离开/断线会结束游戏。它不是当前最主要的练级障碍。
- **显示问题**：README 记录换图音乐中断、装备面板残留槽，部分面板需要重登刷新。当前客户端是否逐项复现仍待验证。

## 四、GM 和运维上的实际坑

1. **帮助内容不完全准确。** `/quest`、`/ball reset` 的主聊天解析未接通；短别名在客户端去掉 `/` 后可能被过滤。见[中文GM手册](GM_COMMANDS.zh-CN.md)中的可用长别名与替代方式。
2. **不要公开这个本地服。** GM 分派没有管理员权限隔离，新账号自动注册；这不是审核过的公网部署方案。多人接入前要补鉴权和访问控制，而不是简单开端口。
3. **存档以SQLite为真源。** `data/cuentas.db`，自动备份在 `data/backups/`，JSON为镜像。强制杀服务端可能丢失仍在内存的经验/位置，先正常退到登录界面。
4. **本机停止脚本不等于可靠整树停服。** 当前虚拟环境 Python 启动出实际监听的子进程；`stop-local.ps1`只按保存的父PID停止，可能留下子进程导致端口占用。此次只记录，没有另行修运维脚本或停止运行中的服务器。
5. **不要把客户端自动补丁目录改错。** `start-local.ps1` 的 `AO_CLIENTE` 指向项目内 `client-local`，与实际用来游玩的简体目录不同；目的是避免把面向IGG固定二进制偏移的补丁直接写进简体客户端。换季节、解除技能互斥、延长通行证、自定义道具等客户端补丁不能假设已经在简体端生效。

## 六、推荐的游玩顺序

1. 主号先以常规剑、弓、生命/大地等基础路线体验教学、四城、野外、商店和仓库；这只是降低未知风险的建议，不是这些职业每招都已验收的保证。
2. 影刃/刺客与30/32换技能已修复服务端关联，仍建议用小号做中文客户端实机验收；400+道具、宠物高阶融合、大型赛事也应逐项测，先备份。
3. 新道具先查[中文目录](../data/localization/items.zh-CN.html)，缺映射、测试、隐藏或跨版本物品先不要大量发。
4. 遇到NPC无响应、门不通、物品没效果，记录**地图、NPC/物品ID、点击选项、时间**；连同该时刻服务端日志就能定位，而不是只靠README猜。
